# LazyVim setup bootstrap script
 this script setup `LazyVim` based on my prefrence and custom keys etc what i want here 
it's install all of these things make it ready to use

## Requirement for this script
- ubuntu, kali or debian like os
- Arch and RHEL based LINUX
- Andriod via Termux



## how to use my script
to setup you don't need to do anything just copy below command and paste into your **LINUX/andriod's termux** shell
```bash
bash <(curl -sSL https://raw.githubusercontent.com/mdsameer2924/Personal-script-t/refs/heads/main/neovim_setup/src/setup.sh)
```
