# Neovim's Lazyvim this setup's Cheetsheet
## Make quick changes to multiple area at once

1. **in normal mode** `:%s/targeted_word/new_word/g`

## Flash cursor
2. **in normal mode**: `s` + <targetplace_word> + it's appear red between that word press that key boom you got there 
**`eg`**: `s` + `h` + red  **a** letter appear between h press now cursor go there
